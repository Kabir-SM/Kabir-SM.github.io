# Kabir Marwaha Portfolio

A cinematic, responsive portfolio for Kabir Marwaha, a computer science and AI
student focused on software engineering, automation, data, and systems
integration.

## Highlights

- Interactive, physics-inspired profile badge
- Resume-driven projects and experience timeline
- Expandable project impact details
- Responsive design with reduced-motion support
- Downloadable resume and direct contact links

## Local development

```bash
pnpm install
pnpm run dev
```

## Production build

```bash
pnpm run build
```
